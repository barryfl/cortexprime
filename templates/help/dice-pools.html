Dice Pools and Rolling

Use Add to Dice Pool on a rollable Trait to build the pool. Deliberately adding dice opens the Dice Pool automatically, and temporarily adjusted Traits contribute their current effective die.

The pool is a temporary staging tray: closing it or completing a successful roll clears it.

Rolling

Roll the assembled pool using the Dice Pool controls.

Total

Select the dice used to form your Total according to the rules of your game.

Effect Die

Select one unused die as the Effect Die.

Hitches

Dice that roll 1 are treated as hitches and are identified by the roll interface.

Re-Roll

The Re-Roll controls allow an existing pool to be rolled again when permitted.

To Pool

Roll results or selected dice can be returned to the active pool where appropriate.

Export to Macro

Build a pool, then choose Export to Macro to save a reusable launcher. Actor Traits remain linked where possible, so using the macro reconstructs and opens the pool with their current effective values instead of rolling immediately.

Exported macros are placed in a Cortex Prime Dice Pools folder named for the user.
