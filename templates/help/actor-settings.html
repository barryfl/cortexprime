Actor Configuration

Actor Settings defines the structure used when new Cortex Prime actors are created.

Actor Types

Actor Types define which sections appear on an actor sheet and which Trait Sets, Simple Traits, and other features are available.

General Actor Settings

  • Show Profile Image: Displays the actor portrait on the sheet.
  • Has Notes Page: Adds the Notes tab.
  • Has Plot Points: Enables Plot Point tracking.
  • Has Assets: Enables Assets.
  • Has Complications: Enables Complications.
  • Has Hidable Traits: Allows traits to be hidden from other users.

Trait Sets

Trait Sets are major categories such as Distinctions, Attributes, Skills, Relationships, or Values.

Use the plus button under Trait Sets to create a new category, then configure the Trait Set before adding preset traits.

Preset Traits

Preset Traits are traits automatically included in the Trait Set when a new actor is created.

Examples include Strength, Dexterity, Intelligence, or predefined Distinctions.
